# Problem Statement

Managing personal finances manually becomes difficult due to unorganized spending records, lack of analytics, and no budget monitoring. Users need a simple system to track expenses efficiently.

# Scope of the Project
The Smart Personal Finance Manager allows users to record expenses, view analytics, manage budgets, and generate reports. The system uses CSV storage for persistence and provides an interactive console-based interface.

# Target Users
- Students
- Employees
- Anyone needing simple finance tracking

# High-Level Features
- Expense CRUD operations
- CSV-based data storage
- Category-wise analysis & summary
- Budget management and alerts
- Report generation module
